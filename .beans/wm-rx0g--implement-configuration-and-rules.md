## Summary of Changes

- Added a strict JSONC configuration module with defaults, workspace inheritance, generated schema output, semantic validation, and unknown-field rejection at every modeled level.
- Added compositional first-match window rules supporting exact/contains/regex, case sensitivity, AND/OR/NOT, modeled window properties, and initial action intents.
- Added an atomic configuration store with a separate runtime overlay, delta/full and hotload/explicit defaults, rejection retention, degraded/recovered health state, and deterministic events.
- Added shared WebSocket methods and CLI commands for configuration validation/reload plus configuration and health event topics.
- Added focused deterministic parsing, inheritance, rule, reload reducer, and CLI parity tests.

## Unmet Acceptance Criteria

- Rule action intents are modeled and tested but are not yet applied by the managed-window lifecycle to newly discovered windows.
- Reload stores validated config atomically and emits events, but does not yet reconcile configured workspace creation/removal or execute a full drift reconciliation pass.
- The schema is supplied by the configuration module but is not generated by a build-time schema generator.
