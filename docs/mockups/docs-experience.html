#Errors

CodeMeaningWhat to do
window_not_found No live window matches the target. List live windows with wm windows and retry with a current ID.

The no-op case (alone at the edge) is success, not an error.

#Invocation

MethodInvocation
CLI wm window move workspace <workspace> Moves the focused window and follows it; also spelled wm workspace move-window <workspace>. wm workspace move-window <window-id> <workspace> Moves a specified window without switching your view. Example: wm workspace move-window w1 writing. Find a current ID with wm windows.
Keybind ⌥⇧1 "option+shift+1": "window move workspace <workspace>" Assign a shortcut to a concrete command in your config. Keybinds guide ↗
WebSocket {"type":"moveFocusedWindowToWorkspace","workspace":"<workspace>"}Send a command payload to the local service. WebSocket protocol ↗
Scenario "window move workspace <workspace>"Use this command in a playground or docs demo, or in a test. Scenario format ↗

#Arguments

NameTypeNotes
windowWindow ID →Required in the explicit-ID form; the other forms use the focused window.
workspaceWorkspace name →Any name; new workspaces are created on first use.

#Errors

CodeMeaningWhat to do
window_not_found No live window matches the target. List live windows with wm windows and retry with a current ID.
workspace_not_found No workspace has that name. Check spelling — names are created on first use, so this only fails on a strict lookup.
paused The window manager is paused and holds mutations. Resume with wm resume (or your pause keybind), then retry.

wm doctorgenerated page

Check the local installation: sidecar reachability, macOS permissions, and service state. Runs locally — it never contacts the daemon.

#Invocation

MethodInvocation
CLI wm doctor No keybind or WebSocket row: doctor reads your machine directly, so it only exists in the terminal.

#Exit codes

CodeMeaningWhat to do
0 All checks passed. Nothing — you are set.
1 At least one check failed; the JSON output names it. Run wm permissions-request for permission failures, then wm doctor again.

Installation

Paneform wm ships as a signed macOS service with a wm CLI. This page previews the authored-markdown style.

Setup steps

Requirements

  • macOS 14 or newer, Apple silicon or Intel
  • Node 24 (CLI only)

Install

wm service install registers and starts the launchd service. The daemon owns no windows until you start it.

Grant permissions

wm needs Accessibility and Screen Recording. Run wm permissions-request to open both prompts, then wm doctor to verify. See the doctor page for a sample run →

Write a config

Configuration lives at ~/.config/paneform/wm/config.jsonc and hot-reloads on save.
