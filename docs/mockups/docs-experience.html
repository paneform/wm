Move window directionallygenerated page

Swap the focused window with its neighbor in a direction, expanding along the display edge when the edge is free of neighbors.

Example command: wm window move left

#Invocation

Method Invocation
CLI wm window move <direction>
Keybind "option+h": "window move <direction>" in keybinds Chords accept modifiers ⌥⌃⌘⇧ and one key — bind one chord per direction. Assign a shortcut to a concrete command in your config. Keybinds guide ↗
WebSocket {"type":"moveDirection","direction":"<direction>"}Send a command payload to the local service. WebSocket protocol ↗
Scenario "window move <direction>"Use this command in a playground or docs demo, or in a test. Scenario format ↗

#Arguments

Name Type Values
direction enum left, right, up, down

#Errors

Code Meaning What to do
window_not_found No live window matches the target. List live windows with wm window list and retry with a current ID.
paused The window manager is paused and holds mutations. Resume with wm resume (or your pause keybind), then retry.

The no-op case (alone at the edge) is success, not an error.

Move to workspacegenerated page

Move the focused window and follow it to another workspace, or target a window by ID without switching your view.

Example command: wm window assign 2

#Invocation

Method Invocation
CLI wm window assign <workspace> Assigns the focused window and follows it. wm window assign <workspace> --window <window-id> --no-follow Assigns a specified window without switching your view. Example: wm window assign 2 --window w1 --no-follow. Find a current ID with wm window list.
Keybind ⌥⇧1 "option+shift+1": "window assign <workspace>" Assign a shortcut to a concrete command in your config. Keybinds guide ↗
WebSocket {"type":"moveWindowToWorkspace","workspace":"<workspace>","follow":true}Send a command payload to the local service. WebSocket protocol ↗
Scenario "window assign <workspace>"Use this command in a playground or docs demo, or in a test. Scenario format ↗

#Arguments

Name Type Notes
window Window ID → Required in the explicit-ID form; the other forms use the focused window.
workspace Workspace name → Any name; new workspaces are created on first use.

#Errors

Code Meaning What to do
window_not_found No live window matches the target. List live windows with wm window list and retry with a current ID.
workspace_not_found No workspace has that name. Check spelling — names are created on first use, so this only fails on a strict lookup.
paused The window manager is paused and holds mutations. Resume with wm resume (or your pause keybind), then retry.

wm permissionsgenerated page

Check the local installation: sidecar reachability, macOS permissions, and service state. Runs locally — it never contacts the daemon.

#Invocation

Method Invocation
CLI wm permissions No keybind or WebSocket row: doctor reads your machine directly, so it only exists in the terminal.

#Exit codes

Code Meaning What to do
0 All checks passed. Nothing — you are set.
1 At least one check failed; the JSON output names it. Run wm permissions request for permission failures, then wm permissions again.

Installation

Paneform wm ships as a signed macOS service with a wm CLI. This page previews the authored-markdown style.

Setup steps

Requirements

  • macOS 14 or newer, Apple silicon or Intel
  • Node 24 (CLI only)

Install

wm service install registers and starts the launchd service. The daemon owns no windows until you start it.

Grant permissions

wm needs Accessibility and Screen Recording. Run wm permissions request to open both prompts, then wm permissions to verify. See the permissions page for a sample run →

Write a config

Configuration lives at ~/.config/paneform/wm/config.jsonc and hot-reloads on save.
